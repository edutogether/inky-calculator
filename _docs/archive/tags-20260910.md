## 실행 순서 — Voice Cinema가 넣은 순서 그대로

1. `git update-ref refs/archive/tags/<이름> <커밋>`
2. `git push origin refs/archive/tags/<이름>`
3. **`git ls-remote origin "refs/archive/tags/*"`로 서버에 다시 물어봐 실제 커밋으로
   풀리는지 확인** — "방금 푸시했다"를 로컬 명령의 성공 여부로만 믿지 않았다.
   실제로 두 ref 모두 기대한 커밋 해시(`9985e57…`·`db7440d…`)와 정확히 일치함을 확인했다.
4. 그다음에야 `git tag -d`·`git push origin :refs/tags/<이름>`으로 원래 태그를 지웠다.
