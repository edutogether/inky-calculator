# 태그 정리 — 2026-09-10 (1단계: 제안, 팀장 확인 대기 중)

`git tag`·GitHub 태그 목록에서 3개 중 2개를 `refs/archive/tags/<원래이름>`으로 옮기자는
제안이다. **지우는 게 아니다** — 커밋은 그대로 살아 있고, 옮긴 뒤에도
`git checkout refs/archive/tags/<이름>`으로 언제든 돌아갈 수 있다.
**팀장 확인 전에는 실행하지 않는다.**

## 옮기는 것(2개) — `refs/archive/tags/<이름>`으로

**왜 옮기는가**:

- **`pre-firebase`**: GitHub Pages → Firebase Hosting 이전 직전 지점이다. 이전은
  대표 결정으로 확정됐고(`CLAUDE.md`·`app.md`가 명시적으로 "임시 구조가 아니라 최종

  이 지점으로 되돌아가려면 그 뒤의 커밋 40개 이상(부호·색상·SRI·입력 검증·첫 감사 수정

  판단해 옮기는 쪽으로 제안한다.
- **`pre-tests`**: vitest 테스트를 넣기 바로 직전 지점("테스트 0개" 상태)이다. 그 뒤
  테스트가 15개까지 늘었고, 첫 종합감사에서 §5.4/§21 기준으로 전부 변이 검사까지 마쳤다
  — "테스트가 잘못됐으니 그 전으로 되돌아가자"가 될 이유가 없다. 옮기는 쪽으로 제안한다.

## 실행 예정 명령(팀장 확인 후에만)

```bash
for t in inky-calculator-freeze-20260909-pre-firebase inky-calculator-freeze-20260910-pre-tests; do
  commit=$(git rev-list -n1 "$t")
  git update-ref "refs/archive/tags/$t" "$commit"
  git tag -d "$t"
  git push origin ":refs/tags/$t"
  git push origin "refs/archive/tags/$t"
done
```
