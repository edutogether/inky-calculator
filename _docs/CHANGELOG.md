## 2026-09-09

**Firebase Hosting으로 이전하고, 라이브에서 나온 결함 다수를 그날 안에 고쳤다.**

- 공개 주소를 GitHub Pages(`edutogether.github.io/inky-calculator`)에서
  **Firebase Hosting `calc.edutogether.kr`**로 옮겼다. CSP를 sha256 해시로(`'unsafe-inline'`
  없이) 걸고, 배포 워크플로가 CSP 해시·권장안 상한·부호를 검사한 뒤 배포하고 배포 후
  보안 헤더까지 확인하도록 만들었다(`.github/workflows/firebase-hosting.yml`,
  `scripts/check-*.js`).
- 첫 Firebase 배포에서 `.git` 디렉터리가 통째로 공개 배포되는 사고가 있었다(`**/.*` 패턴이
  하위 경로를 잡지 못함) — `firebase.json`의 ignore 목록을 고쳐 바로잡았다.
- **부호 결함**: 돈이 남는데 화면에 `-15,988원`으로 뜨던 것을 고쳤다. 계산은 맞았고 표시
  단계에서 `-`를 하드코딩해 둔 것이 원인이었다 — 남으면 `+`, 초과하면 `−`, 딱 맞으면
  부호 없음(`signed()`)으로 통일했다.
- **집행률 색 경계**: 화면은 소수 1자리로 반올림해 보여 주는데 판정은 원값으로 하고 있어
  같은 "100.0%"가 어떤 땐 초록·어떤 땐 빨강으로 보이던 것을 고쳤다. 판정을 화면 표시값
  기준으로 바꾸고, 정확히 100%는 초록(예산을 다 쓴 것은 최선)으로 확정했다.
- **게이지 막대 색**: 막대가 집행률과 다른 규칙(`pct>92`)을 써서 98.9%는 초록인데 막대는
  주황이던 것을, 막대도 `rateClass()`를 그대로 쓰도록 통일했다.
- **구분 번호**: 공통·부스·협의회비 여섯 구분에 ⓪①②③④⑤ 번호를 붙여 하나의 순서로
  보이게 했다.
- **탭 제목·파비콘**: 탭 제목을 `InKY Calculator`로, 파비콘을 🧾 이모지 SVG(`data:` URI)로
  추가했다. 탭이 비활성이면 흑백으로 바뀐다.
- **협의회비 개편**: 물품을 고를 때마다 협의회비 지급액이 뒤에서 자동으로 따라 계산되던
  것을 없앴다. 첫 진입에만 자동 계산을 한 번 돌려 권장안을 정하고, 그 뒤로는 사람이
  「자동 계산」을 눌러야만 값이 바뀐다.
- **인당 지원금액 상한**: 30,000원 → **40,000원**으로 정정하고(근거 문서 재확인),
  안내창에 근거 문서 링크 두 개(편성지침·집행지침)를 각각 무엇인지 설명과 함께 걸었다.
- **협의회비 총액 상한**: 배정 예산의 **40%**로 확정(문서 근거는 못 찾아 안내창에 법령
  링크는 붙이지 않음).
- **자동 계산 알고리즘**: 지급액 → 횟수 → 인원 순으로 맞추고, 흔한 조합(1회·10~20명)을
  먼저 탐색하며, 목표선(인당 10,000원) 이상 중 남는 돈이 가장 적은 조합을 고르도록 정리했다.
- **인쇄**: A4 세로 6쪽 기준으로 레이아웃을 맞추고, 마지막 쪽에 협의회비와 견적 합계가
  함께 나오도록 고쳤다. `.moutw`의 `flex:0 0 auto` 누락으로 좁은 화면·인쇄물에 빈 공간이
  생기던 것도 함께 고쳤다.
- `intent` 워크플로를 도입하고(`_docs/intents/`, `.claude/rules/intent-workflow.md`),
  이 저장소 전용 판단·사고 기록을 `.claude/rules/app.md`에 모았다.
